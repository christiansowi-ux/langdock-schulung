Die Learnings von Tag 3

Das Wichtigste in einem Satz – „Nochmal erklärt“ öffnet die einfache Erklärung. Was sitzt, abhaken; was unklar ist, melden.

  1. 01

    Hinter dem Chatfenster steckt ein Weg in fünf Stationen.

    Nochmal erklärt

    Anfrage → Transport → Load Balancer → API → Rechenzentrum. Und die Antwort nimmt denselben Weg zurück.

    Folie 2 ansehen
  2. 02

    Station 1 – Die Anfrage: Man sieht nur die Oberfläche.

    Nochmal erklärt

    Man tippt in einer App oder im Browser, zum Beispiel in Langdock. Die eigentliche „Intelligenz“ läuft nicht auf dem eigenen Gerät, sondern woanders. Die Nachricht verlässt das Gerät und geht ins Internet.

    Folie 3 ansehen
  3. 03

    Station 2 – Transport: Die Anfrage reist verschlüsselt.

    Nochmal erklärt

    Die Anfrage wird über HTTPS/SSL verschickt – wie ein versiegelter Brief, den unterwegs niemand lesen kann. Sie landet beim Modellanbieter, z. B. OpenAI, Google oder Anthropic. „Request“ ist nur das Fachwort für Anfrage.

    Folie 4 ansehen
  4. 04

    Station 3 – Load Balancer: Er verteilt die Anfragen.

    Nochmal erklärt

    Millionen Menschen fragen gleichzeitig. Der Load Balancer schickt jede Anfrage an einen freien Server – wie ein Weichenstellwerk am Bahnhof. Ohne ihn wäre alles überlastet.

    Folie 5 ansehen
  5. 05

    Station 4 – API: die Schnittstelle zum Modell.

    Nochmal erklärt

    Die API leitet die Anfrage an das richtige KI-Modell weiter, übersetzt sie in ein Format, das das Modell versteht, und bringt die Antwort zurück. API heißt „Application Programming Interface“ – eine Schnittstelle, über die Programme miteinander sprechen.

    Folie 6 ansehen
  6. 06

    Station 5 – Rechenzentrum: Hier läuft das Sprachmodell.

    Nochmal erklärt

    Ein Gebäude voller Hochleistungsrechner. Dort laufen die großen Sprachmodelle (LLMs), z. B. GPT-5.5 oder Opus 4.8. Die schwere Rechenarbeit übernehmen Spezialchips (GPUs oder TPUs).

    Folie 7 ansehen
  7. 07

    Im Rechenzentrum wird zuerst der Kontext zusammengebaut.

    Nochmal erklärt

    Kontext = alles, was die KI für genau diese Frage bekommt: die Frage selbst, den bisherigen Chat und angehängte Dateien. Was nicht darin steht, kennt die KI nicht.

    Folie 7 ansehen
  8. 08

    Der Text wird in Tokens zerlegt.

    Nochmal erklärt

    Tokens sind kleine Textstücke: ganze Wörter, Wortteile oder Zeichen. Lange Wörter werden oft in mehrere Stücke geteilt. Mit diesen Stücken rechnet das Modell.

    Folie 7 ansehen
  9. 09

    Aus Tokens werden Zahlen, die Bedeutung abbilden.

    Nochmal erklärt

    Jedes Stück bekommt eine Zahlenreihe (ein „Vektor“, der Vorgang heißt „Embedding“). Wörter mit ähnlicher Bedeutung bekommen ähnliche Zahlen – deshalb „weiß“ die KI, dass König näher an Königin liegt als an Apfel.

    Folie 9 ansehen
  10. 10

    Die Antwort entsteht Token für Token.

    Nochmal erklärt

    Das Modell rechnet ein Stück nach dem anderen aus und schickt jedes sofort los. Deshalb erscheint die Antwort live, Stück für Stück, auf dem Bildschirm – das nennt man Stream.

    Folie 7 ansehen
  11. 11

    Danach wird der Zwischenspeicher geleert.

    Nochmal erklärt

    Ist die Antwort fertig, wird der Speicher der Spezialchips (Cache) für die nächsten Anfragen anderer Menschen freigemacht.

    Folie 7 ansehen
  12. 12

    Fehlt etwas im Kontext, erfindet die KI eher, als dass sie nachfragt.

    Nochmal erklärt

    Aus dem Prompt-Labor (Modul 01): Eine fehlende Angabe erzeugt keine Fehlermeldung, sondern eine plausible Erfindung. Darum gibt man der KI alles Nötige mit – oder sagt ihr, was sie bei Lücken tun soll.

Lernkarten

Frage lesen, Antwort überlegen, Karte umdrehen. Dann ehrlich einsortieren: gewusst oder nochmal.

  1. Welche fünf Stationen durchläuft eine KI-Anfrage?Anfrage → Transport → Load Balancer → API → Rechenzentrum.
  2. Wie wird die Anfrage übertragen?Verschlüsselt über HTTPS/SSL – wie ein versiegelter Brief.
  3. Was macht der Load Balancer?Er verteilt die vielen Anfragen auf freie Server – wie ein Weichenstellwerk.
  4. Was macht die API?Sie leitet die Anfrage ans richtige Modell, übersetzt sie in ein passendes Format und bringt die Antwort zurück.
  5. Wo läuft das Sprachmodell?Im Rechenzentrum, auf Spezialchips (GPUs/TPUs).
  6. Was ist der Kontext?Alles, was die KI für diese Frage bekommt: Frage, bisheriger Chat, Anhänge.
  7. Was ist ein Token?Ein kleines Textstück – ein Wort, ein Wortteil oder ein Zeichen.
  8. Was ist ein Embedding?Zahlen, die die Bedeutung eines Textstücks abbilden. Ähnliche Bedeutung = ähnliche Zahlen.
  9. Warum erscheint die Antwort Stück für Stück?Sie wird Token für Token berechnet und sofort geschickt (Stream).
  10. Was passiert nach der Antwort mit dem Zwischenspeicher?Der Cache wird geleert – für die Anfragen anderer.
  11. Was tut die KI, wenn eine Angabe fehlt?Sie füllt die Lücke meist mit einer plausiblen Erfindung, statt nachzufragen.

Selbsttest

6 kurze Fragen. Nach jeder Antwort steht sofort da, warum. Nichts wird bewertet – es ist nur für einen selbst.

  1. In welcher Reihenfolge läuft eine Anfrage?

    1. Anfrage → API → Transport → Rechenzentrum → Load Balancer
    2. Anfrage → Transport → Load Balancer → API → Rechenzentrum
    3. Rechenzentrum → API → Anfrage → Transport → Load Balancer

    Warum: Erst verlässt die Anfrage das Gerät, reist verschlüsselt, wird verteilt, von der API übersetzt und im Rechenzentrum berechnet.

  2. Was macht der Load Balancer?

    1. Er macht die Antwort inhaltlich besser
    2. Er verteilt Anfragen auf freie Server
    3. Er verschlüsselt die Nachricht

    Warum: Wie ein Weichenstellwerk schickt er jede Anfrage zu einem freien Server.

  3. Was sind Tokens?

    1. Kleine Textstücke, mit denen das Modell rechnet
    2. Passwörter für die Anmeldung
    3. Die Preise pro Anfrage

    Warum: Der Text wird in kleine Stücke zerlegt – ganze Wörter, Wortteile oder Zeichen.

  4. Warum „tippt“ die KI ihre Antwort Stück für Stück?

    1. Damit es spannender wirkt
    2. Weil die Antwort Token für Token berechnet und sofort geschickt wird
    3. Weil das Internet langsam ist

    Warum: Jedes Stück wird berechnet und direkt übertragen – das ist der Stream.

  5. Was bedeutet Embedding?

    1. Das Einbetten eines Videos
    2. Textstücke werden zu Zahlen, die Bedeutung abbilden
    3. Das Speichern des Chats

    Warum: Ähnliche Bedeutungen bekommen ähnliche Zahlen – so erkennt die KI, was zusammengehört.

  6. Was passiert, wenn im Prompt eine wichtige Angabe fehlt?

    1. Die KI meldet einen Fehler
    2. Die KI füllt die Lücke meist mit einer plausiblen Erfindung
    3. Die KI antwortet gar nicht

    Warum: Eine Lücke erzeugt keine Fehlermeldung, sondern eine Erfindung – darum den Kontext mitgeben.
