JSON ist wie ein Zettel mit beschrifteten Feldern

Stell dir diesen kleinen Zettel vor:

BeschriftungWas auf dem Zettel steht
projektPapierfunke
themaWorkshop am 30.10.
kanalInstagram
statusENTWURF

Ohne Beschriftung wäre „Papierfunke, Workshop, Instagram“ schwerer zuzuordnen. Die Beschriftungen sagen Make genau, welche Angabe wofür gedacht ist.

Und was ist daran JSON?

JSON ist eine feste Schreibweise für solche Angaben. Computerprogramme können sie gut austauschen und wieder auseinanderlesen. Es ist keine KI und du musst dafür heute nicht programmieren.

Wichtig

Instagram ist in unserem Beispiel nur Text auf dem Zettel. Dieses Wort verbindet kein Konto und veröffentlicht nichts.

04 / 28 · Modul 2 · Lektion 1 · Tag 2/4 · Dienstag, 27.10.2026 · Schritt für Schritt

Du musst nur diese Schreibregeln erkennen

Nur zum Lesen: ein kleines JSON-Beispiel
{
  "thema": "Workshop am 30.10."
}

Das vollständige Muster zum Einfügen steht in Schritt 2.

Links steht der Feldname thema. Rechts steht sein Inhalt Workshop am 30.10. Der Doppelpunkt trennt beides. Die doppelten Anführungszeichen gehören bei diesen Texten dazu.

ZeichenBedeutung
{ und }Hier beginnt und endet der gesamte Zettel.
"thema"Die Beschriftung eines Feldes.
:Jetzt folgt der Inhalt dieses Feldes.
"Workshop am 30.10."Der Text, der in diesem Feld steht.
,Trennt zwei Felder. Hinter dem letzten Feld steht kein Komma.
Wichtig

Für unsere Übung kopierst du das vollständige Muster im Bauschritt. Keine zusätzlichen ```-Zeichen, Überschriften oder Erklärsätze mitkopieren. Ändere zunächst keine Klammern oder Feldnamen.

05 / 28 · Modul 2 · Lektion 1 · Tag 2/4 · Dienstag, 27.10.2026 · Schritt für Schritt

Vier Werte übernehmen - statt alles fest einzutippen

Wenn du den fertigen Satz „Projekt: Papierfunke“ vollständig in den zweiten Baustein tippst, bleibt Papierfunke dort fest stehen. Auch dann, wenn das Projekt vorne inzwischen anders heißt.

Deshalb tippst du nur „Projekt: “ und wählst danach das Feld projekt aus dem ersten Baustein. So wird immer dessen aktueller Inhalt eingesetzt. Für Thema, Kanal und Status machst du es genauso.

  1. Feste Beschriftung: Projekt: plus Leerzeichen
  2. Ausgewähltes Feld: projekt
  3. Später im Ergebnis: Projekt: Papierfunke
Kurz prüfen

Merksatz: Die Beschriftung tippe ich. Den wechselnden Inhalt wähle ich als Datenfeld aus.

Wichtig

Ein farbiges Datenfeld ist nicht dasselbe wie getippter Text in eckigen Klammern. Tippe also nicht [projekt] als Ersatz für die Auswahl ein.

Schritt 2: Die vier Testangaben einfügen

Mach das

  1. Kopiere nur den folgenden JSON-Text. Im Web hilft dir der Kopieren-Knopf.
  2. Füge ihn im Baustein Parse JSON in das Feld JSON string ein.
  3. Lass Data structure zunächst leer, wenn das angeboten wird.
  4. Bestätige den Baustein und speichere den Ablauf. Noch keinen zweiten Baustein anschließen.

Was bedeutet Data structure?

Das ist eine Beschreibung, welche Felder Make erwarten soll. Bei unserem einfachen Beispiel kann Make sie beim ersten manuellen Lauf aus dem Muster erkennen. Du musst dafür heute kein eigenes Schema entwerfen.

Wichtig

Der Text oben sind Übungsdaten für JSON string. Er ist keine importierbare Make-Vorlage und gehört nicht zu „Import blueprint“. Der nächste Schritt ist Run once. [M8]

Du siehst die vier Angaben getrennt voneinander. Der erste Baustein hat den Text lesbar aufgeteilt. Erst jetzt fügst du den nächsten hinzu.

Falls es nicht klappt

Ein JSON-Fehler? Kopiere das vollständige Muster noch einmal. Prüfe besonders Anführungszeichen und Kommas. Keine Felder zur Auswahl? Kontrolliere, ob dieser erste Lauf tatsächlich erfolgreich war.

Mach das

  7. Schreibe in eine letzte neue Zeile fest: Noch keine Veröffentlichung.
  8. Bestätige und speichere.

Schritt 6: Andere Angaben, derselbe Ablauf

Jetzt prüfen wir, ob der zweite Baustein wirklich die aktuellen Angaben übernimmt. Tausche dafür nur die Testdaten im ersten Baustein aus.

Mach das

Zum Nachlesen: Ein Zettel oder eine Liste?

JSON-BegriffSo erkennst du ihnAlltagsbild
ObjectGeschweifte Klammern { }Ein einzelner Zettel mit benannten Feldern.
ArrayEckige Klammern [ ]Eine geordnete Liste, etwa mehrere Projekte.

Unser Muster beginnt mit { und endet mit }. Es ist genau ein Objekt. Eine JSON-Liste kann dagegen mehrere Einträge enthalten. Wenn Parse JSON eine solche Liste verarbeitet, können mehrere Datenpäckchen entstehen. Nachfolgende Bausteine können dadurch mehrfach laufen.

Wichtig

Heute bleiben wir bei einem einzigen Objekt. Das hält Ergebnis und Verbrauch überschaubar. In Make heißt das Päckchen Bundle. Die Folien verwenden teilweise das allgemeinere Wort Item.

So hängen die Folienthemen zusammen

  1. Angaben kommen hinein
  2. Ein Schritt liest oder verarbeitet sie
  3. Einzelne Felder werden ausgewählt
  4. Der nächste Schritt verwendet diese Felder

Eine Variable ist ein benannter, veränderlicher Wert. Gestern war es vorname. Heute sind es projekt, thema, kanal und status. Der zweite Test zeigt: Derselbe Ablauf kann andere Inhalte übernehmen.

Die Folien erweitern den Weg später um KI: Eingabe → KI-Auftrag → Antwort in festen JSON-Feldern → Felder auslesen → nächste Aktion. Diese klare Ordnung hilft Programmen, Daten auszutauschen. Für unsere heutige Übung brauchen wir den KI-Schritt noch nicht.

Wichtig

Ein korrekt lesbares JSON beweist keine richtigen Inhalte. Auch eine KI kann einen falschen Termin in sauberem JSON ausgeben. Deshalb prüfst du sowohl die Schreibweise als auch die Bedeutung der Angaben.

24 · JSON

JSON ordnet Angaben in benannte Felder und Listen. Das erleichtert das Austauschen und Lesen zwischen Programmen. Bei KI kann eine vereinbarte JSON-Ausgabe helfen; JSON allein macht eine Antwort aber nicht wahr. Unsere Übung nutzt dieses Format ohne KI.
